# Канал Telegram

Telegram — это исходящий канал уведомлений на основе Telegram Bot API.

Он может отправлять уведомления об алертах и может поддерживать встроенные действия, когда включена обработка опроса/колбэков.

## Обязательная конфигурация канала

Типичная конфигурация:

```json
{
  "bot_token": "123456789:AA...",
  "chat_id": "-1001234567890"
}
```

`bot_token` должен содержать двоеточие. Используйте BotFather для создания бота и получения токена.

## Воркер Telegram

Если используются действия или опрос Telegram, запустите сервис воркера Telegram, если ваша установка его предоставляет:

```bash
systemctl enable --now incidentrelay-telegram-worker
```

Для установок из RPM:

```bash
journalctl -u incidentrelay-telegram-worker -f
```

## Telegram ID пользователя

У пользователя в профиле может быть Telegram user ID. Он может использоваться для атрибуции действий и будущих сценариев прямого взаимодействия с пользователем.

## Прокси

Если серверу нужен прокси для доступа к Telegram, настройте прокси глобально. Храните bot token и chat ID в конфигурации канала.

## Устранение неполадок

Проверьте:

1. Токен содержит `:`.
2. Бот добавлен в целевой чат или канал.
3. `chat_id` корректен.
4. Воркер запущен, если ожидаются действия.
5. Прокси настроен, если сервер не может напрямую достичь Telegram.

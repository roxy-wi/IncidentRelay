# Канал Telegram

Telegram — это исходящий канал уведомлений на основе Telegram Bot API.

Он отправляет уведомления об алертах и поддерживает встроенные действия Acknowledge, Resolve, Shelve и Unshelve, когда включена обработка polling/callback. Кнопки Shelve задаются параметром `shelve_durations` в секции `[telegram]` (по умолчанию `1h`; можно добавить `4h` и `7d`).

## Обязательная конфигурация канала

Типичная конфигурация:

```json
{
  "bot_token": "123456789:AA...",
  "chat_id": "-1001234567890"
}
```

`bot_token` должен содержать двоеточие. Используйте BotFather для создания бота и получения токена.

## Воркер Telegram

Если используются действия или опрос Telegram, запустите сервис воркера Telegram, если ваша установка его предоставляет:

```bash
systemctl enable --now incidentrelay-telegram-worker
```

Для установок из RPM:

```bash
journalctl -u incidentrelay-telegram-worker -f
```

## Несколько каналов на одном боте

`getUpdates` принадлежит токену бота, а не каналу. Каналы с одним и тем же `bot_token` опрашиваются один раз, а нажатие обрабатывает канал, чей id записан в подписанном callback (`ir:<action>:<alert>:<channel>:<signature>`). Нажатие для канала, который этот бот не обслуживает, отклоняется, и сообщение не редактируется. Разные токены по-прежнему опрашиваются по очереди.

## Telegram ID пользователя

У пользователя в профиле может быть Telegram user ID. По нему определяются действия с кнопок. Когда задан `[telegram] dm_priorities`, тот же id — это личный чат, куда пишет бот. Пользователь должен один раз нажать Start у бота, иначе Telegram отклонит сообщение. Отказ пишется в журнал, пост в канале при этом отправляется.

## Личные сообщения

При пустом `dm_priorities` поведение не меняется. При `dm_priorities = p1,p2` уведомление или напоминание с таким приоритетом дополнительно пишет назначенному в личный чат: заголовок, короткий журнал, те же кнопки и ссылку на пост в канале. Эскалация пишет новому назначенному при любом приоритете. Acknowledge, Resolve и Shelve из личного сообщения обновляют и его, и пост в канале.

## Прокси

Если серверу нужен прокси для доступа к Telegram, настройте прокси глобально. Храните bot token и chat ID в конфигурации канала.

## Устранение неполадок

Проверьте:

1. Токен содержит `:`.
2. Бот добавлен в целевой чат или канал.
3. `chat_id` корректен.
4. Воркер запущен, если ожидаются действия.
5. Прокси настроен, если сервер не может напрямую достичь Telegram.

## Shelving

В интерактивном сообщении доступны настроенные кнопки Shelve (по умолчанию **Shelve 1h**) и **Unshelve**. Telegram-пользователь должен быть связан с IncidentRelay user и иметь responder-доступ к команде алерта. Подробнее: [Shelving](../usage/shelving.md).

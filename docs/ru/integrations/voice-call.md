# Канал голосовых вызовов

Голосовой вызов — это исходящий канал уведомлений. Он звонит на номер телефона из профиля назначенного пользователя через глобально настроенного голосового провайдера.

## Модель доставки

```text
Alert assignee -> assignee.phone -> configured voice provider
```

Необходимые данные:

| Расположение | Требуемое значение |
|---|---|
| Профиль пользователя | `phone` |
| Глобальная конфигурация | настройки провайдера `[voice]` |
| Конфигурация голосового канала | опциональная политика канала и фильтр по важности |

## Глобальная конфигурация голоса

```ini
[voice]
provider = stub
providers_dir = /usr/local/lib/incidentrelay/voice_providers
callback_secret = change-me
```

Пользовательские провайдеры описаны в разделе [Голосовые провайдеры](../voice-providers/index.md).

## Фильтр по важности

Используйте общий фильтр канала по важности:

```json
{
  "notify_on_severities": ["critical"]
}
```

Не используйте ключи важности, специфичные для канала.

## Действия DTMF

Пользовательский провайдер может поддерживать действия DTMF для сценариев ACK/Resolve. См.:

- [API провайдера](../voice-providers/provider-api.md)
- [Колбэки и DTMF](../voice-providers/callbacks.md)
- [Безопасность](../voice-providers/security.md)

## Кнопка теста

Тест канала использует номер телефона из профиля текущего пользователя.

Реальная доставка алертов использует номер телефона из профиля назначенного пользователя.

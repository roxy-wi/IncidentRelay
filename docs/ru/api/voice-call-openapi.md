# Заметки по Voice Call OpenAPI

Каналы голосовых вызовов используют тот же API каналов уведомлений, что и другие типы каналов.

Сам голосовой провайдер настраивается глобально и описан в разделе Voice Providers.

Для доставки голосового вызова у назначенного пользователя должен быть указан номер телефона в профиле.

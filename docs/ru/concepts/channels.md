# Каналы

Канал — это место назначения исходящих уведомлений.

Поддерживаемые типы каналов:

```text
mattermost
telegram
slack
webhook
discord
teams
email
voice_call
```

Браузерные push-уведомления намеренно не перечислены здесь. Они действуют на уровне профиля: пользователи включают их в профиле, и IncidentRelay отправляет push-уведомления на активные браузерные/PWA-устройства назначенного пользователя.

Подробнее: [Браузерные push-уведомления](../usage/browser-push.md).

Каналы не имеют токенов приёма алертов. Маршрут получает алерты через свой токен приёма маршрута, а затем отправляет уведомления в один или несколько каналов.

```text
Incoming alert -> Route -> Notification channels
```

## Фильтр серьёзности канала

Канал может ограничивать, какие серьёзности алертов он получает, с помощью `notify_on_severities`:

```json
{
  "notify_on_severities": ["critical", "high"]
}
```

Если ключ отсутствует или пуст, канал получает все серьёзности, привязанные к его маршруту.

Используйте канонические имена серьёзностей:

```text
critical
high
medium
warning
low
info
```

## Каналы, которые требуют контактных полей пользователя

Некоторые каналы отправляют уведомления напрямую назначенному пользователю.

| Канал | Требуемое поле профиля пользователя |
|---|---|
| `email` | `email` |
| `voice_call` | `phone` |

Для тестов каналов IncidentRelay должен использовать соответствующее поле профиля текущего пользователя.

## Каналы, которые поддерживают действия

Некоторые каналы могут поддерживать действия ACK/Resolve прямо из сообщения.

| Канал | Поддержка действий |
|---|---|
| Mattermost Bot API | Кнопки ACK/Resolve и обновления сообщений |
| Slack Bot API | Кнопки ACK/Resolve и обновления сообщений через HTTP-действия или Socket Mode |
| Telegram | Инлайн-действия и обновления сообщений |
| Голосовой вызов | Действия DTMF, если провайдер поддерживает колбэки |
| Email | Нет интерактивных действий |
| Входящий webhook Slack, Discord, Teams, универсальный webhook | Только одностороннее уведомление |

Браузерные push-уведомления также могут включать действия ACK/Resolve, но браузерные push-уведомления действуют на уровне профиля и не настраиваются как канал.

Подробнее в [Каналы уведомлений](../integrations/channels.md).

# Напоминания и эскалации

IncidentRelay может отправлять повторные напоминания о неподтверждённых активных (firing) алертах и эскалировать алерт к следующему дежурному (on-call) пользователю после настроенного количества напоминаний.

## Интервал напоминаний

Интервал напоминаний настраивается на ротации.

```text
0       disables reminders for this rotation
>= 60   enables reminders with this interval in seconds
1..59   invalid
```

Примеры:

| Значение | Смысл |
|---:|---|
| `0` | Не отправлять напоминания |
| `60` | Отправлять напоминания каждые 60 секунд |
| `300` | Отправлять напоминания каждые 5 минут |
| `900` | Отправлять напоминания каждые 15 минут |

## Интервал планировщика в сравнении с интервалом напоминаний

У планировщика есть собственный интервал пробуждения. Это значение управляет тем, как часто планировщик проверяет наличие работы.

Интервал напоминаний ротации управляет тем, наступил ли для конкретного алерта срок напоминания.

Это разные настройки:

```text
scheduler interval       -> how often the scheduler wakes up
rotation reminder interval -> how often alerts assigned by that rotation receive reminders
```

## Когда напоминания прекращаются

Напоминания прекращаются, когда алерт:

- подтверждён (acknowledged);
- разрешён;
- заглушён;
- больше не активен (firing);
- назначен через ротацию с интервалом напоминаний `0`.

## Эскалация после напоминаний

Настройка команды `Escalate after reminders` управляет тем, сколько напоминаний отправляется перед тем, как алерт эскалируется к следующему дежурному (on-call) пользователю.

Пример:

```text
reminder_interval_seconds = 300
escalation_after_reminders = 2
```

Алерт эскалируется после двух сообщений-напоминаний, если он всё ещё не подтверждён.

Если напоминания отключены значением `0`, эскалация на основе напоминаний не будет прогрессировать для алертов, использующих эту ротацию.

# Основные концепции

Ресурсы IncidentRelay организованы вокруг групп, команд, сервисов, ротаций, маршрутов и каналов.

| Концепция         | Описание                                                                    |
|-------------------|--------------------------------------------------------------------------------|
| Группа            | Граница доступа и область администрирования на уровне группы                 |
| Пользователь      | Человек, который может входить в систему, быть на дежурстве (on-call), получать уведомления или использовать персональные API-токены |
| Команда           | Операционная единица внутри группы                                           |
| Ротация           | Расписание дежурств (on-call) для команды                                    |
| Маршрут           | Правило маршрутизации входящих алертов с собственным токеном приёма          |
| Сервис            | Логическая затронутая система, такая как API, база данных, очередь, веб-сайт или компонент инфраструктуры |
| Бизнес-сервис     | Бизнес-сервисы описывают клиентские или бизнес-ориентированные возможности, которые зависят от одного или нескольких технических сервисов. |
| Политика эскалации | Политика эскалации                                                          |
| Канал             | Место назначения исходящих уведомлений                                       |
| Алерт             | Алерт, созданный или обновлённый входящей интеграцией                        |
| Заглушка (silence) | Временное правило, которое подавляет уведомления для соответствующих новых алертов |
| Переопределение (override) | Временная замена в ротации                                          |

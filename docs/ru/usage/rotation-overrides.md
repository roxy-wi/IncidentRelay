# Переопределения ротации

Переопределения ротации временно заменяют рассчитанного дежурного пользователя.

Используйте переопределения для:

- отпуска;
- планового обслуживания;
- обмена сменами;
- разовых изменений покрытия;
- временного отсутствия.

## Как работают переопределения

Переопределение принадлежит ротации и имеет временное окно.

Когда календарь или назначение алерта рассчитывается внутри этого временного окна, вместо обычного итогового результата по слоям используется пользователь из переопределения.

Приоритет:

```text
override > highest-priority active layer > no assignment
```

## Переопределения и слои

Слои определяют обычное расписание. Переопределения — это временные исключения.

Пример обычной настройки слоя:

```text
Layer: Business hours
Members: Ivan -> Petr -> Anna
Active: Monday-Friday 09:00-18:00
```

Пример переопределения:

```text
User: Sergey
Window: 2026-05-25 12:00 -> 2026-05-25 16:00
Reason: Ivan is unavailable
```

В течение окна переопределения Сергей отображается в календаре и используется для назначения алертов.

## Поведение календаря

Календарь разбивает затронутые смены вокруг окна переопределения.

Пример:

```text
09:00-12:00 Ivan
12:00-16:00 Sergey override
16:00-18:00 Ivan
```

## Удаление ротации

При удалении ротации:

- ротация помечается как удалённая (soft-delete);
- её слои помечаются как удалённые (soft-delete);
- участники слоёв и ограничения удаляются;
- переопределения ротации удаляются;
- маршруты сохраняются, но их `rotation_id` очищается.

## Рекомендуемые практики

- Делайте окна переопределений как можно более короткими и точными.
- Добавляйте понятную причину.
- Проверяйте календарь после создания переопределения.
- Удаляйте или корректируйте некорректные переопределения.
- Не используйте переопределения для постоянных шаблонов расписания; вместо этого используйте слои и ограничения.

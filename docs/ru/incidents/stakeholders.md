# Заинтересованные стороны инцидента

Заинтересованные стороны инцидента (stakeholders) — это люди, которые должны оставаться в курсе инцидента, не обязательно являясь активным ответственным или назначенным.

Заинтересованные стороны полезны для:

- владельцев сервисов;
- владельцев бизнеса;
- контактов поддержки;
- контактов по работе с клиентами (customer success);
- руководителей или других наблюдателей.

## Снимки заинтересованных сторон

Когда инцидент создаётся для сервиса, IncidentRelay может скопировать заинтересованные стороны сервиса по умолчанию в список заинтересованных сторон инцидента.

Это снимок:

- новые заинтересованные стороны сервиса по умолчанию влияют только на новые инциденты;
- существующие инциденты сохраняют собственный список заинтересованных сторон;
- заинтересованные стороны инцидента можно редактировать напрямую, не меняя значения по умолчанию для сервиса.

Подробнее: [Заинтересованные стороны сервиса по умолчанию](../services/default-stakeholders.md).

## События уведомлений

Заинтересованные стороны могут получать уведомления о событиях жизненного цикла:

| Событие | Описание |
|---|---|
| Created | Для сервиса был создан новый инцидент. |
| Priority changed | Ответственный изменил приоритет инцидента вручную. |
| Status changed | Инцидент был подтверждён (acknowledged) или изменил статус. |
| Resolved | Инцидент был разрешён. |

## Каналы уведомлений

Уведомления заинтересованным сторонам являются информационными.

Они могут доставляться через:

- email, если у заинтересованной стороны есть адрес электронной почты;
- браузерные push-уведомления, если заинтересованная сторона — активный пользователь IncidentRelay с включёнными браузерными push-уведомлениями.

Браузерные push-уведомления заинтересованным сторонам не включают кнопки действий ACK или Resolve.

# Проверка схемы

Поддерживайте согласованность схем запросов, документации OpenAPI и форм UI.

Типовые проверки:

- если поле присутствует в теле запроса Swagger, оно должно присутствовать в соответствующей схеме запроса;
- если схема отклоняет поле из-за `extra="forbid"`, Swagger не должен объявлять это поле;
- значения enum должны использовать те же константы, что и валидация на бэкенде;
- старые значения ролей, такие как `read_only` и `rw`, не должны появляться в схемах запросов после миграции;
- для Email-канала `recipient_mode` и `recipient_email` должны совпадать с валидацией схемы, а настройки транспорта SMTP остаются глобальными.

Рекомендуемые локальные проверки:

```bash
pytest tests
python3 -m compileall -q app tests
```

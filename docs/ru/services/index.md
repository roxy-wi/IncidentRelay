# Сервисы

Сервисы описывают затронутые системы внутри IncidentRelay: API, базы данных, очереди, веб-сайты, компоненты инфраструктуры или бизнес-сервисы.

## Почему сервисы важны

Маршруты отвечают на вопрос, как алерт попал в IncidentRelay.

Сервисы отвечают на вопрос, какая система затронута.

Контекст сервиса может улучшить:

- маршрутизацию и сортировку;
- обнаружение runbook'ов;
- видимость владельцев и заинтересованных сторон;
- анализ влияния зависимостей;
- операционную аналитику.

## Рекомендуемая настройка

1. Создайте сервисы для систем, которыми управляют ваши команды.
2. Добавьте владение, ссылки и runbook'и.
3. Настройте правила сопоставления сервисов или сервисы маршрутов по умолчанию.
4. Создайте политики уведомлений для общих правил доставки сервиса.
5. Назначьте политики уведомлений сервисам.
6. Выберите нужный режим канала уведомлений на маршрутах.
7. Добавьте заинтересованные стороны сервиса по умолчанию, когда уведомления о жизненном цикле полезны.
8. Просматривайте влияние сервиса и аналитику во время реагирования на инцидент.

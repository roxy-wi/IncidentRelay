# Планирование

Планирование охватывает модель дежурств (on-call), используемую для назначения инцидентов нужным ответственным.

Используйте этот раздел для понимания поведения расписания дежурств:

- [Команды, ротации, слои и маршруты](../concepts/teams-rotations-routes.md)
- [Календарь](../usage/calendar.md)
- [Слои ротации](../usage/rotation-layers.md)
- [Переопределения ротации](../usage/rotation-overrides.md)

## Расчёт расписания

IncidentRelay вычисляет фактического дежурного пользователя на основе слоёв ротации и переопределений.

```text
rotation override
  -> highest-priority active layer
  -> no assignment
```

Используйте слои ротации для повторяющейся структуры расписания, а переопределения — для временных замен.

## Синхронизация календаря

Расписания дежурств можно просматривать в IncidentRelay и экспортировать во внешние календарные клиенты.

- [Синхронизация календаря по CalDAV](../integrations/caldav.md)
